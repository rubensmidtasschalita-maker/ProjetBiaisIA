# Culture et Enjeux du Numérique - Biais de genre des IA

## Présentation

Ce projet est une enquête sur les biais de genre des grands modèles de langage (Large Language Models, ou LLM).

Nous avons mené plusieurs expériences afin d'identifier et d'analyser les biais de genre de ces modèles, en les comparant notamment à la littérature sur le sujet.
